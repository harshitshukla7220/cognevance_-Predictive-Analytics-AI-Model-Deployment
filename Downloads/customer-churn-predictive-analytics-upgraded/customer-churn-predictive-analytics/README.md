# Predictive Analytics & AI Model Deployment — Customer Churn

An end-to-end machine-learning project that predicts whether a telecom customer is likely to leave. It uses the supplied Telco Customer Churn dataset (7,043 customer records), compares multiple models, generates evaluation reports, serves predictions through FastAPI, and provides a Streamlit analytics dashboard.

## Coverage of the 8 internship tasks

| # | Requirement | Implementation |
|---|---|---|
| 1 | Collect a large business dataset | `data/customer_churn.csv` includes 7,043 customer records and 21 columns. |
| 2 | Advanced preprocessing and feature engineering | Numeric/categorical imputation, scaling, one-hot encoding, ID removal, numeric conversion and derived tenure, service-count and billing features. |
| 3 | Train multiple ML models | Logistic Regression, Random Forest, Extra Trees, Gradient Boosting and Scikit-learn MLP. |
| 4 | Compare performance | Cross-validation PR-AUC and held-out accuracy, balanced accuracy, precision, recall, F1, ROC-AUC, PR-AUC and MCC. |
| 5 | Predictive analytics / deep learning | Customer churn risk prediction, probability scoring and training-only decision-threshold tuning. MLP neural network is included. |
| 6 | Deploy model | FastAPI `/predict` and `/predict/batch`, Dockerfile and Docker Compose. |
| 7 | Dashboard and reports | Streamlit dashboard, model comparison, churn chart, confusion matrix and downloadable JSON/Markdown reports. |
| 8 | Architecture and workflow | `ARCHITECTURE.md`, README, reproducible commands and CI tests. |

## Windows setup (Python 3.11 recommended)

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements-dev.txt
```

## Run the complete workflow

Run these commands from the project root:

```powershell
python -m src.data_audit
python -m src.train
pytest -q
```

The training command creates:
- `models/best_model.joblib`
- `reports/model_metrics.json`
- `reports/model_report.md`
- `images/confusion_matrix.png`

Start the API:

```powershell
uvicorn src.app:app --reload
```

Open API documentation: http://127.0.0.1:8000/docs

Start the dashboard in another PowerShell window:

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run dashboard/dashboard.py
```

Dashboard: http://localhost:8501

## Dataset and limitations

The included CSV is the Telco Customer Churn dataset from the original supplied project. The project retains its existing dataset and customer-churn topic. Results are dataset-specific and should not be interpreted as guaranteed real-world churn outcomes. Evaluate privacy, fairness, drift and business impact before production use.

## Verified training run included in this ZIP

The bundled model and reports were generated by running the standard training workflow on the included 7,043-row dataset with a stratified 80/20 split and 3-fold cross-validation.

- Selected model (highest mean CV PR-AUC): **Logistic Regression**
- Held-out accuracy at tuned threshold: **0.7679**
- Held-out precision: **0.5465**
- Held-out recall: **0.7380**
- Held-out F1: **0.6280**
- Held-out ROC-AUC: **0.8425**
- Held-out PR-AUC: **0.6371**

These are measured results from the included dataset and one fixed split, not a guarantee of future performance. See `reports/model_report.md` for the complete model comparison.
